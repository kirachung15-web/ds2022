# GitHub Skills Reflection

Through the GitHub Skills exercises, I learned how to use branches, commits, pull requests, and reviews to manage changes to a project. I learned how branches allow changes to be made separately from the main version of a project before merging them. I also learned how to review pull requests, leave comments, suggest specific changes, and apply those suggestions. These exercises helped me understand how GitHub can be used for collaboration and keeping track of changes to a project.
